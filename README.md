# Tribute Page: Dr. A.P.J. Abdul Kalam

## 📌 Project Overview
A visually engaging, fully responsive tribute page dedicated to Dr. A.P.J. Abdul Kalam – the "Missile Man of India" and former President of India. Built with HTML5 and CSS3, this page honours his life, achievements, and enduring legacy through a carefully designed layout featuring a hero section, biography, quote block, timeline, and legacy section.

## 🛠️ Tech Stack
- **HTML5** – Semantic structure
- **CSS3** – Flexbox, Grid, custom properties, responsive design
- **Google Fonts** – Merriweather (serif for headings) and Inter (sans-serif for body)
- **Font Awesome** – Icons (optional – used for accent visuals)

## ✅ Features Implemented
- [x] Page title with subject's name and one-line tagline
- [x] A prominent image (royalty‑free from Wikimedia Commons)
- [x] Biography / tribute section with 4 original paragraphs
- [x] Timeline / key achievements section (5 styled cards with years)
- [x] Quote block with a notable quote from Dr. Kalam
- [x] At least 2 different background colours used across sections:
  - Dark navy gradient (Hero)
  - Light cream (Quote section)
  - Dark navy (Legacy section)
  - Light warm (Tribute and Timeline)
- [x] At least 2 font styles:
  - Merriweather (serif) for headings and quotes
  - Inter (sans-serif) for body text
- [x] Fully responsive – works on desktop, tablet, and mobile
- [x] Smooth scroll navigation between sections

## 🎨 Design Highlights
- **Typography Contrast**: Serif headings paired with clean sans-serif body text
- **Colour Palette**: Deep navy, gold accents, and warm cream tones
- **Visual Hierarchy**: Clear section separation with varied backgrounds
- **Interactive Elements**: Hover effects on timeline cards and hero image
- **Quote Styling**: Distinctive blockquote with decorative quotation mark
